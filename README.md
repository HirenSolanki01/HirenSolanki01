## 🚀 Featured Projects

### 1. 🔍 InfoSurf – AI-Powered Research Assistant

An intelligent research assistant built using Retrieval-Augmented Generation (RAG) to retrieve relevant information from documents and provide context-aware responses.

- Document processing, text extraction, and intelligent chunking.
- Semantic search using vector embeddings.
- Context-aware responses with source citations.
- LLM-powered question answering.

**Tech Stack:** Python, FastAPI, LLMs, MiniLM, Qdrant, RAG.

🔗 [View Repository](https://github.com/HirenSolanki01/InfoSurf)

### 2. ⭐ Fake Review Detection System

An NLP and Machine Learning-based application designed to identify potentially fake or misleading product reviews.

- Text preprocessing and feature extraction.
- Natural Language Processing for review analysis.
- Machine Learning-based classification.
- Flask-based application interface.

**Tech Stack:** Python, Machine Learning, NLP, Transformers, Flask.

🔗 [View Repository](https://github.com/Siddhesh1207/Fake_Review_Detection_System)

### 3. ☁️ CloudVault – Secure Cloud File Storage Platform

A cloud-based file storage and management application that enables users to securely upload, store, access, and manage files using cloud infrastructure.

- Firebase Authentication for secure user registration and login.
- Firestore for managing user and file metadata.
- Amazon S3 for scalable cloud file storage.
- Firebase Cloud Functions for backend operations.
- Firebase Hosting for application deployment.

**Tech Stack:** HTML, CSS, JavaScript, Firebase Authentication, Firestore, Amazon S3, Firebase Cloud Functions, Firebase Hosting.

🔗 [View Repository](https://github.com/HirenSolanki01/CloudVault)
